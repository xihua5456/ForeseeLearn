1|# 智能学习助手系统
2|
3|## 核心理念
4|通过智能算法帮您制定最优学习计划，让学习更高效、更有针对性。
5|
6|## 系统架构
7|```
8|智能学习助手/
9|├── data/           # 学习数据管理
10|├── models/         # 学习效果预测
11|├── engine/         # 计划优化引擎
12|├── config/         # 系统配置
13|├── utils/          # 实用工具
14|└── main.py         # 主程序入口
15|```
16|
17|## 智能功能
18|1. **智能评分**：根据正确率和自评给学习打分
19|2. **时间优化**：自动分配最合理的学习时间
20|3. **进度跟踪**：实时掌握每个知识点的学习进度
21|4. **个性化建议**：根据您的学习情况给出改进建议
22|
23|## 使用方法
24|1. 运行 `python main.py` 启动系统
25|2. 选择您需要的功能
26|3. 记录每天的学习情况
27|4. 获取智能学习建议
28|
29|## 功能模块
30|每个功能都可以单独使用，也可以组合使用。
31|
32|## 快速开始
33|- Windows: 双击 `start_fixed.bat`
34|- 或直接运行 `python main.py`
35|
36|## 主要功能
37|- 自动生成学习计划
38.- 跟踪学习进度
39.- 智能优化学习参数
40.- 提供个性化学习建议
